Privacy Policy

Menu Bar Calendar · Last updated October 22, 2026

Menu Bar Calendar runs only on its owner's own Mac.

What it accesses. With read-only permission (calendar.readonly), it reads the user's Google Calendar list and the events for today and tomorrow, so they can be shown in the macOS menu bar.

Where data is kept. Event details and the sign-in token are stored only on that Mac, in ~/.config/menubar-calendar/. Nothing is sent to any server other than Google's own APIs.

Sharing. No data is sold, shared, or sent to third parties. There is no analytics or tracking.

Removing access. Access can be revoked at any time at myaccount.google.com/permissions. Deleting the folder above removes all stored data.

Menu Bar Calendar's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
